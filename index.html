Run it locally

Clone the repo and run in a few commands:

# 1. Clone the repo
git clone https://github.com/Reamogetse12/chatbot.git
cd chatbot

# 2. Install dependencies (uses uv)
pip install uv
uv sync

# 3. Add your Groq API key to .env
echo GROQ_API_KEY=your_key_here > .env

# 4. Launch the chatbot
python chatbot.py

This is an interactive demo — responses are simulated in the browser.
For the real AI experience, run it locally with your Groq API key.
